Quickstart

Send an image as multipart/form-data under the field file and include your API key in X-Api-Key.

Important
Do not set Content-Type manually. Your HTTP client will set the correct multipart/form-data boundary automatically.
cURL
curl -X POST "https://aiclipse.online/api/v1/checks" \
  -H "X-Api-Key: <YOUR_API_KEY>" \
  -H "Accept: application/json" \
  -F "file=@./image.jpg"

Authentication

Use an API key via request header X-Api-Key. Each user has one active key. Generating a new key invalidates the previous one immediately.

Header
X-Api-Key: <YOUR_API_KEY>

Endpoint: POST /v1/checks

Runs AI detection for a single image and returns verdict, confidence, and a short-lived detection_token.

Examples

cURL
curl -X POST "https://aiclipse.online/api/v1/checks" \
  -H "X-Api-Key: <YOUR_API_KEY>" \
  -H "Accept: application/json" \
  -F "file=@./image.jpg"
Python (requests)
import requests

url = "https://aiclipse.online/api/v1/checks"
headers = {
  "X-Api-Key": "<YOUR_API_KEY>",
  "Accept": "application/json",
}
files = {
  "file": ("image.jpg", open("image.jpg", "rb"), "image/jpeg")
}

res = requests.post(url, headers=headers, files=files, timeout=60)
print(res.status_code, res.json())

Postman

Recommended
Use Postman’s API Key auth. It still sends the key as a header — it’s just a cleaner UI for managing it.
  1. Set URL: https://aiclipse.online/api/v1/checks
  2. Authorization → Type: API Key
    Key: X-Api-Key
    Value: <YOUR_API_KEY>
    Add to: Header
  3. Headers: Accept = application/json
  4. Body → form-data → key file (type File) → pick an image
Important
Do not add Content-Type manually in Headers. Postman will set the correct boundary automatically.
Common mistake
If the field name is not exactly file, FastAPI returns 422 with “Field required”.

Errors

Missing/invalid API key

Limits

  • Formats: JPEG, PNG
  • Max file size: 20 MB
  • Max dimensions: 12000×12000
  • Max pixels: 40 MP
